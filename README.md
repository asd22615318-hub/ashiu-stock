# 阿修型態研選

GitHub Pages 公開版。將 Pages 的部署來源設為 GitHub Actions。
排程為台灣時間每日 17:30；GitHub 排程可能延遲。官方更新失敗時，工作流程失敗並保留上次發布。
頁面只讀取已發布的行情；「重新載入行情」不會直接觸發官方更新。CSV 匯入僅在使用者瀏覽器處理。

公開資料：官方股票代號、名稱、產業分類、日期、OHLC、成交量與擷取時間。
不包含使用者提供的講義或圖片、個人資訊、金鑰、原始公司基本資料快取、本機路徑及 Sites 設定。
完整均線排名需 361 筆日線，成交量固定 > 500 張。技術規則的暫定口徑見網站說明。

Windows Python 執行 `python build.py --offline` 可建立已審查快照；`python build.py` 會向官方抓取盤後行情後建立發布檔案。
