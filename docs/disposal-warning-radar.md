# 處置預警雷達：資料與驗證規格（2026-10-08）

## 已完成
- 新增 `disposal_warning.py`：解析明確標示的第一至第十款、計算第一款連三、第一至八款連五、十日六次及三十日十二次；提供圖片百分比反推工具。
- 新增 `tests/test_disposal_warning.py`：測試累計邏輯與圖片參考價。
- 所有截圖的門檻仍是「待驗證樣本」，不是官方預測值。

## 目前資料缺口（禁止以零代替）
1. 必須取得**完整逐日**官方注意資訊，包含沒有公告的交易日，並以官方交易日曆排序。現有 `prison_data.py` 只保存當日警示與累計摘要，無法直接精算所有回溯窗口。
2. 收盤價門檻要依上市/上櫃當期有效版本的異常標準，計算六日/九十日基期、全市場與同類股比較、價差及除外條件。
3. 成交量門檻要核對對應款次的成交量倍數、週轉率、股本分母、全市場比較與除外條件，不能僅用 5% 流通股數假設。
4. 已處置中再次處置須獨立處理，不得用一般首次處置條件替代。
5. 日期：截圖為 2026-10-08 收盤後，預測目標為 2026-10-09。
