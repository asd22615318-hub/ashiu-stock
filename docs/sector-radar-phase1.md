# 族群雙軌資金雷達（第一階段）
## 已實作
- 延用原本族群 STOCK_GROUPS 與既有市場、法人、集保快照，無需新 API。
- 量價分數：相對成交值 35%、等權平均單日漲幅 30%、上漲家數比例 35%。
- 籌碼分數：近五日法人淨買超占成交量 65%、400 張以上集保持股率週變化 35%；缺項按現有權重重新正規化。
- 綜合分數：量價 60%＋籌碼 40%；籌碼完全缺漏則顯示 —。
- 同時展示量價、籌碼與綜合分數及上漲占比；保留原有族群檢視入口。
## 資料限制
- 此處的「資金」為交易活躍度與持股變化代理指標，不是實際淨資金流入。
- 族群可重疊，族群成交額不可跨群直接相加成全市場成交額。
- 缺少券商分點逐日歷史資料，不能宣稱已納入分點主力。
- 目前仍沿用 STOCK_GROUPS，尚未完成所有上市櫃公司的細分產業逐股核實。
- 既有法人和集保快照更新日期可能不同；畫面應以各自日期為準。
## 第二階段待辦
1. 新增 sectors.json：sector_id、parent_id、level、kind、name、source、verified_at。
2. 新增 stock_sector_memberships.json：code、sector_id、is_primary、exposure_weight、source、verified_at、status。
3. 從官方上市櫃股票母集合建立覆蓋率報告，人工複核跨產業標籤。
4. 新增 3/5/10/20 日視窗、歷史快照與加速度；以同期間的歷史百分位評分。
5. 接入合法分點歷史資料後，獨立計算分點籌碼，並避免與法人買超重複解讀。
## 驗收
- GitHub Pages 原有選股、營收、ETF、處置股與個股明細仍能開啟。
- 法人或集保缺值時不當作 0；籌碼全部缺失不顯示虛構綜合分數。
- 僅有 2 檔成員的族群不列入本版排名。
- 官方成交金額可用時優先使用，否則以收盤價×成交張數估算。
